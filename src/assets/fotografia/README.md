# Imágenes del catálogo

Seis imágenes ilustrativas de producto, con una estética cálida y artesanal coherente con la portada `../ritual-grano.png`.

| Archivo | Producto |
| --- | --- |
| `colombia.webp` | Café Colombia, notas de cacao y caramelo |
| `etiopia.webp` | Café Etiopía, notas florales y cítricas |
| `blend.webp` | Blend de la casa, notas de chocolate y avellanas |
| `dripper.webp` | Dripper de cerámica |
| `prensa.webp` | Prensa francesa |
| `taza.webp` | Taza de cerámica |

Las imágenes usan el formato WebP de 1200 × 1200 píxeles. El catálogo, las fichas de detalle, el carrito y los enlaces de métodos comparten estos recursos.
