# Fotografía de producto Grano

Serie ilustrativa generada con la herramienta integrada OpenAI Imagegen el 30 de octubre de 2026. No son fotografías de productos físicos. La referencia visual es `../ritual-grano.png`, la portada original, que se conserva.

Las seis imágenes comparten luz cálida de ventana desde la izquierda, mesa de nogal, lino verde bosque, fondo doméstico desenfocado y materiales tangibles. Las bolsas llevan papel kraft y etiqueta crema; la cerámica es color arena. No se añaden certificaciones ni promesas comerciales.

Cada archivo `.webp.json` conserva el prompt completo, la herramienta, la referencia y la conversión aplicada. Los originales generados se redujeron proporcionalmente a 1200 × 1200 y se codificaron como WebP con calidad 86, sin editar las escenas. El catálogo, los detalles, el carrito y los enlaces de métodos comparten estos mismos recursos.

Nosotros reutiliza la portada, la taza y el café Colombia. Los productos nuevos sin foto usan la portada como imagen ilustrativa de respaldo. Las imágenes propias cargadas desde administración se conservan.
